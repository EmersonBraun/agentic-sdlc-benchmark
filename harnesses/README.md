# Harnesses

Harness adapters implement the common benchmark contract for:

- Reference Harness;
- OpenHands SDK;
- mini-SWE-agent.

Adapters must expose semantic parity for workspace, shell, Git, GitHub, browser, oracle, permissions, context, and ledger operations.

The reference adapter is the only contract-ready implementation at this stage. OpenHands SDK and mini-SWE-agent remain explicitly declared integrations until their exact versions and parity checks are frozen.
