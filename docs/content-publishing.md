# Public Content and Dashboard

The static GitHub Pages dashboard has two modes:

- exploratory: filters, comparisons, timelines, task details, failures, and AgentsKit ablations;
- editorial: versioned narratives, charts, insights, and links to evidence.

Every published insight references the dataset version, protocol version, task, and `run_id`. Observation, interpretation, and opinion must be clearly separated.

MVP outputs remain in the same repository through branches and immutable tags. Official analysis uses finalized tags only.

The current snapshots and their release criteria are listed in
[`release-map.md`](release-map.md).
