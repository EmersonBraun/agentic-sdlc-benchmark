# Release Map

MVPs remain in this repository and are identified by immutable tags. Branches
are working surfaces; tags are the evidence snapshots used for citations and
publication.

| Snapshot | Meaning | Run status |
|---|---|---|
| `protocol-v1.0` | Historical frozen protocol and repository scaffold | No pooled v1.1 results |
| `mvp-v1.1-preflight` | v1.1 protocol, public task/PRD, readiness evidence, controller, analysis, and dashboard | 0/18 conditions ready; no runs |
| `mvp-v1.1-pilot-results` | Reserved for the first verified pilot release | Created only after collection and evaluation |

The current development branch is `master`. A matching `mvp/v1.1-preflight`
branch points to the preflight snapshot for inspection; result branches and
tags must be created only from immutable collected evidence.
